# Инструкция к приложению Telegram Chat

## Подготовка: регистрация в GREEN-API

Перед запуском приложения необходимо подготовить инстанс GREEN-API. Без этого шага приложение не сможет отправлять и принимать сообщения.

### Шаг 1. Регистрация

1. Перейдите на [green-api.com](https://green-api.com/) и зарегистрируйтесь.
2. Подтвердите email и войдите в **личный кабинет**.

### Шаг 2. Создание инстанса

1. В личном кабинете нажмите **«Создать инстанс»**.
2. Выберите бесплатный тариф.
3. После создания вы получите:
   - **`idInstance`** — числовой идентификатор инстанса (например, `410022757613`)
   - **`apiTokenInstance`** — длинный токен доступа

Сохраните эти два значения — они понадобятся для входа в приложение.

### Шаг 3. Авторизация Telegram в инстансе

Инстанс нужно привязать к вашему Telegram-аккаунту.

1. Откройте созданный инстанс в личном кабинете.
2. Нажмите **«Авторизоваться»** (или **«Получить QR-код»**).
3. Откройте Telegram на телефоне → **Настройки** → **Устройства** → **Подключить устройство**.
4. Отсканируйте QR-код из личного кабинета GREEN-API.
5. Дождитесь, пока статус инстанса сменится на **`authorized`**.

### Шаг 4. Настройка уведомлений

Это **самый важный шаг** — без него входящие сообщения не будут доходить до приложения.

В настройках инстанса (кнопка **«Изменить»**):

2. Включите тумблеры уведомлений:
   - **`incomingWebhook`** — получение входящих сообщений
   - **`outgoingWebhook`** — статусы отправленных сообщений
   - **`stateWebhook`** — изменения состояния инстанса

3. Нажмите **«Сохранить изменения»**.

4. **Подождите ~1 минуту** — настройки применяются не сразу.

Без включённого `incomingWebhook` вы не увидите ответы собеседника. Без включённого `outgoingWebhook` вы не увидите статусы своих сообщений.


## Использование

### 1. Вход в приложение

1. Откройте приложение в браузере по ссылке: [chat-bot-tg.vercel.app](https://chat-bot-tg.vercel.app/).
2. Введите:
   - **`idInstance`** — из личного кабинета GREEN-API
   - **`apiTokenInstance`** — из личного кабинета GREEN-API
3. Нажмите **«Войти»**.

Если инстанс не авторизован, появится ошибка с подсказкой завершить авторизацию в личном кабинете.

### 2. Создание чата

1. Введите **номер телефона** получателя в международном формате **без `+`**, например: `79013379520`.
2. Нажмите **«Создать чат»**.
3. Приложение проверит существование Telegram-аккаунта по номеру (`checkAccount`) и получит `chatId`.
   - Если аккаунт не найден — появится ошибка.
   - Если найден — откроется окно чата.

### 3. Отправка сообщения

1. Введите текст в поле внизу экрана.
2. Нажмите кнопку отправки или клавишу **Enter**.
3. Сообщение появится в чате справа и будет доставлено в Telegram получателю.

### 4. Получение ответа

Ответные сообщения приходят автоматически через long-polling. Сообщение от собеседника появится в чате слева.

Если ответ не приходит — проверьте, что в настройках инстанса включён `incomingWebhook` и очищен `webhookUrl` (см. раздел «Настройка уведомлений»).

### 5. Выход

Нажмите кнопку **«Выйти»** в правом верхнем углу. Данные авторизации удалятся из `localStorage`.
